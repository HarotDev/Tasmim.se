Tasmim Webbyrå - Officiell Webbplats
Detta är kodbasen för den officiella webbplatsen för Tasmim, en modern digital byrå som specialiserar sig på webbutveckling, design och digital marknadsföring. Webbplatsen är byggd med ASP.NET Core och är designad för att vara snabb, responsiv och användarvänlig.

Teknisk Stack
Backend: ASP.NET Core MVC (.NET 8)

Frontend: HTML5, CSS3, JavaScript (ES6)

Lokalisering: ASP.NET Core Localization för flerspråksstöd (Svenska & Arabiska)

E-post: MailKit för att skicka transaktionella e-postmeddelanden (beställningar och kontaktformulär)

Huvudfunktioner
Flerspråksstöd: Hela webbplatsen är fullt översatt och funktionell på både svenska och arabiska, inklusive RTL-stöd (Right-To-Left) för arabiska.

Responsiv Design: Fullt anpassad för alla skärmstorlekar, från mobil till desktop.

Dynamiskt Innehåll: Innehåller interaktiva element som CSS-animationer och en "word roller"-effekt för att skapa en engagerande användarupplevelse.

Cookie Consent: En specialbyggd cookie-banner som hanterar användarens samtycke enligt GDPR.

Beställningsflöde: Användare kan beställa tjänstepaket direkt via ett formulär, vilket genererar automatiska bekräftelsemejl till både kund och administratör.

Kontaktformulär: Ett säkert kontaktformulär med validering och skydd mot CSRF.
